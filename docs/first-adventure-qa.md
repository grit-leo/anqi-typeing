## 浏览器实测

使用独立的 `localhost:3001` 与 `localhost:3002` 测试存档，没有清除 `localhost:3000` 的正式存档。

1. 无历史记录的新玩家自动进入故事；有历史记录的玩家仍进入原地图，可以从新入口打开故事。
2. 点击 3D 棉棉进入找花种阶段；点击花种袋或“让棉棉带我过去”，棉棉沿路移动，抵达后进入准备阶段。
3. 准备阶段乱按键显示定位提示；分别按 F、J 后开始按钮启用，键盘 Space 也能操作该按钮。
4. 实际按键完成两段共 12 组、40 个正确字符，第二段默认收起提示；可恢复指法、展开/收起完整键盘。场景显示小芽和逐片开放的花圃。
5. 输入一个错误键后光标不动，随后输入正确键可继续。半行按 Esc 暂停，暂停后按字符不增加成绩；刷新并重新进入故事，恢复到原行的第二个字符。
6. 场景中的位置路牌可点击，卡片位置按钮也可用。选取丁香紫 / 窗边、奶油黄 / 小路旁，花盆在对应位置出现；姓名字段实际用于小院命名。
7. 一次错键的记录显示 98% / 40 字符；无错键新存档显示 100% / 40 字符。新玩家接入 D/K 修桥准备页，刷新主世界仍显示花圃 6/6、6 花种，下一课为 D/K。
8. 旧测试存档的 24 花种变成 30，原「森林的新朋友」第 2 组断点保留；故事下一课入口不会覆盖这段未完成课程，刷新不重复发奖励。
9. 1280×720 默认窗口、1366×768 笔记本窗口下检查故事卡、练习面板及完整键盘；1920×1080 检查完成纪念卡。未发现操作区重叠或水平溢出。已恢复测试窗口尺寸。
10. 完整流程中检查的浏览器错误/警告记录为空。

## 未验证与边界

- 没有进行真实儿童观察测试；没有证实盲打能力、长期记忆或练习意愿的提升。
- 未进行跨浏览器/低端显卡性能基准测试，不承诺固定帧率。
- 旧存档测试服务在热更新后出现过 React 多渲染器 context provider 的服务端警告；页面仍返回 200，浏览器实测未被阻塞。该开发服务器警告尚未单独定位，生产构建与服务端 HTML 测试已通过。
- WebGL 失败与本地存储失败具有代码中的降级入口和提示，但本轮未对浏览器实际强制故障注入。
- 3D 仍使用现有程序化场景与比熊模型，本轮重点是故事、学习与世界反馈的闭环，不是写真级美术重做。
- 下一轮可观察：孩子是否能独立找到入口与花种、F/J 是否用对手指、第二段是否仍依赖提示，以及是否愿意继续修桥；根据实际观察调整内容长度与提示退场时机。
