# 棉棉比熊升级验收 · 2026-09-19

## 本次范围

- `app/BichonCompanion.ts` 独立模型与动作模块，替换小岛内原有球团模型。
- 头脸、胸背和腿部使用连续曲面；添加下垂耳、短口吻、鼻孔、嘴线、细卷毛、背上卷尾与细皮项圈。
- 毛发使用实例化网格；近景 / 中景 / 远景分别保留 100% / 45% / 22%，避免把全部细毛用于远处的小角色。
- 四肢和踝关节步态、呼吸、眨眼、嗅闻、耳朵轻摆、摇尾；暂停冻结姿态，减少动态模式关闭附加动作。
- “近看棉棉”使用同一个实时模型，支持正面、侧面、斜侧面、旋转和缩放；没有照片替身。返回或 Esc 恢复原小岛视角。
- 此版本是程序化、风格化 3D 比熊，仍不是实拍扫描或照片级角色。

## 已验证

- 生产构建、46 项自动化测试、TypeScript、ESLint 均通过。
- 新增 5 项模型测试：完整骨架和有效几何、关节步态且不改导航坐标、暂停及减少动态、眨眼恢复、远景细节与 GPU 资源释放。
- 浏览器检查：进入近景、切换正侧面、Esc 返回、开始练习、输入一组、暂停、保存回岛均正常。
- 验收使用独立 `localhost:3001` 测试存档；没有用测试输入修改 `localhost:3000` 的学习成绩。
- 浏览器控制台未发现 error / warn。
- 实际页面截图：`screenshots/bichon-companion-20260919.png`。

## 后续边界

真实犬只还需要更细的肌肉、毛束和骨骼权重制作。如果继续追求照片级效果，应单独制作或引入有明确授权的高质量比熊模型；不要把当前程序化模型宣传成照片级写实。
